# Homework01 — Unreal Engine

## Домашнее задание №1. Расширение Third Person Template

**Версия Unreal Engine:** 5.8.4

### Реализованные механики

- Создан C++ класс ABaseCharacter, наследуемый от ACharacter.
- BP_ThirdPersonCharacter наследуется от ABaseCharacter.
- Настроены дополнительные действия Enhanced Input: IA_Sprint и IA_Interact.
- Обработка новых действий реализована на C++ через BindAction в SetupPlayerInputComponent.
- Реализована механика спринта с увеличением MaxWalkSpeed до 900 см/с.
- При отпускании клавиши спринта восстанавливается стандартная скорость персонажа.
- Состояние спринта хранится в переменной bIsSprinting с модификатором BlueprintReadOnly.
- Создан Dynamic Multicast Delegate OnInteraction.
- При взаимодействии вызывается делегат, на который подписан BP_ThirdPersonCharacter.
- При нажатии клавиши E выводится сообщение Interaction triggered!
- Сохранены стандартные механики передвижения, прыжка и управления камерой.

### Управление

| Клавиша | Действие |
|---|---|
| W, A, S, D | Передвижение |
| Мышь | Управление камерой |
| Space | Прыжок |
| Left Shift | Спринт |
| E | Взаимодействие |

### Архитектура проекта

- ABaseCharacter — основная логика спринта и взаимодействия на C++.
- BP_ThirdPersonCharacter — Blueprint игрового персонажа.
- IMC_Default — контекст назначения клавиш Enhanced Input.
- IA_Sprint — действие спринта.
- IA_Interact — действие взаимодействия.
- ABP_Unarmed — стандартный Animation Blueprint персонажа.

### Статус выполнения

Основные механики управления, спринта и взаимодействия реализованы и проверены.

Отдельное состояние Sprint в Animation Blueprint и дополнительная механика Stamina не реализованы.

# Домашнее задание №2 — Behavior Trees и PCG

## Используемые технологии

- Unreal Engine 5.8
- C++
- Blueprint
- Procedural Content Generation (PCG)
- Behavior Tree
- Blackboard
- NavMesh

## 1. Процедурная генерация окружения

Расширен существующий уровень Third Person.

Создан граф PCG_Obstacles для процедурной генерации препятствий в виде кубов и цилиндров со случайным масштабом и вращением.

Для объектов настроены коллизии и взаимодействие с навигационной системой.

Добавлен NavMeshBoundsVolume для перемещения ИИ по уровню и обхода препятствий.

## 2. Настройка искусственного интеллекта

Созданы следующие классы и ресурсы:

- EnemyAIController — C++ класс контроллера ИИ.
- BP_EnemyAIController — Blueprint контроллера.
- BP_EnemyCharacter — персонаж ИИ.
- BB_Enemy — Blackboard.
- BT_Enemy — дерево поведения.
- BTT_FindPatrolLocation — кастомная задача поиска точки патрулирования.
- BTS_DetectPlayer — кастомный сервис обнаружения игрока.

## 3. Базовое поведение ИИ

### Патрулирование

NPC выбирает случайную доступную точку в радиусе 1500 см от стартовой позиции.

После достижения точки NPC ожидает 2 секунды, затем продолжает патрулирование.

### Преследование

При обнаружении игрока NPC прерывает патрулирование и начинает преследование с использованием Behavior Tree и NavMesh.

Радиус обычного обнаружения составляет 500 см.

### Потеря цели

При удалении игрока на расстояние более 1200 см ключ TargetActor очищается, после чего NPC возвращается к патрулированию.

## 4. Дополнительное задание на 9–10 баллов

### Реакция ИИ на шум спринта игрока

Реализован кастомный BT Service BTS_DetectPlayer, использующий механику спринта из первого домашнего задания.

Сервис проверяет:

- Расстояние между NPC и игроком.
- Состояние IsSprinting из C++ класса BaseCharacter.
- Горизонтальную скорость игрока.
- Наличие текущей цели в Blackboard.

Если игрок находится в состоянии спринта и его горизонтальная скорость превышает 10 см/с, радиус обнаружения увеличивается с 500 до 1000 см.

Удержание Shift без движения не увеличивает радиус обнаружения.

Реакция на шум реализована посредством имитации слышимости спринта через состояние персонажа и расстояние до NPC.

Сервис установлен на корневой Selector дерева поведения и выполняет проверку каждые 0,2 секунды.

Переключение между патрулированием и преследованием осуществляется через Blackboard Based Condition с параметром Observer Aborts = Both.

## 5. Проверка работы

- Запустить уровень Lvl_ThirdPerson.
- Убедиться, что NPC самостоятельно патрулирует территорию.
- Приблизиться к NPC для начала преследования.
- Убежать за пределы радиуса потери цели.
- Проверить обнаружение игрока при спринте на увеличенном расстоянии.

Управление:

- WASD — перемещение.
- Мышь — управление камерой.
- Space — прыжок.
- Left Shift — спринт.
- E — взаимодействие.

Все реализованные механики проверены в игровом режиме.
